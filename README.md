# JAG ROOFING AND CONSTRUCTION

This repository contains the source code for the official website of JAG Roofing and Construction, a company specializing in roofing and exterior repair services in Corpus Christi, Texas. The website is a fully responsive, single-page static site designed to showcase the company's services, projects, and provide easy ways for potential clients to get in touch.

### [View the Live Website](https://shikhar302001.github.io/JAG_ROOFING/)

## Features

*   **Responsive Design**: The layout adapts seamlessly to various screen sizes, from mobile phones to desktop monitors.
*   **Service Showcase**: An interactive accordion displays the company's primary services, including roof replacement, maintenance, waterproofing, and emergency repairs.
*   **Quick Estimate Forms**: Multiple call-to-action sections and forms allow users to quickly request a free estimate or inspection.
*   **Project Gallery**: A section dedicated to showcasing the latest projects completed by the company.
*   **FAQ Section**: An accordion-style FAQ section to answer common customer questions.
*   **Blog Section**: A visually engaging card-based layout for blog articles with hover effects.
*   **Dynamic Elements**: Includes a scrolling marquee for services and interactive card elements for visual appeal.
*   **Contact & Socials**: Easy access to contact information and social media links in both the header and footer.

## Technologies Used

*   **HTML5**: The core markup for the website content.
*   **CSS3**: Custom styling for layout, colors, animations, and responsiveness.
*   **Bootstrap 5.3.3**: Utilized for its responsive grid system, components (like accordions and navbars), and utility classes.
*   **LEMON MILK Font**: A custom font used for headings and branding to create a distinct visual identity.

## Local Development

To run this project on your local machine:

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/shikhar302001/JAG_ROOFING.git
    ```
2.  **Navigate to the project directory:**
    ```sh
    cd JAG_ROOFING
    ```
3.  **Open the `index.html` file in your web browser.**
    You can simply double-click the file or right-click and select "Open with" your preferred browser.
